# Amiibo Search API Query
Amiibo API Query Search is a API search query for Nintendo Amiibos!
Searching any other characters that is not applicable for the query will not work
such as searching for Creeper (HOWEVER, Characters that are represented on a nintendo game such as SMASH BROS are
applicable where one example is STEVE from minecraft).
## How to Use
You start with the startup page then clicking the lets go button leads you to the search website.
You can search any NINTENDO AMIIBO and it will fetch from a third-party site and shows you the information regarding it
